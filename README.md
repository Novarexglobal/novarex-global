# NOVAREX Global — sitio corporativo

Sitio estático bilingüe (español/inglés) para presentar servicios propuestos de consultoría comercial, intermediación y coordinación de proyectos.

## Contenido
- `index.html`: estructura y contenido del sitio.
- `styles.css`: diseño adaptable a móvil y escritorio.
- `script.js`: cambio de idioma, navegación móvil y formulario local.
- `assets/novarex-mark.svg`: marca vectorial.
- `novarex-global-profile.pdf`: perfil corporativo.
- `.github/workflows/pages.yml`: publicación automática mediante GitHub Pages al subir cambios a `main`.
- `404.html`: página para direcciones no encontradas.

## Publicar gratuitamente con GitHub Pages
1. Inicia sesión en tu cuenta de GitHub y crea un repositorio nuevo llamado `novarex-global`.
2. Sube el contenido de esta carpeta a la raíz del repositorio, incluyendo la carpeta `.github` y el archivo `.nojekyll`.
3. En **Settings → Pages**, selecciona **GitHub Actions** como método de publicación si no se ha seleccionado automáticamente.
4. Abre la pestaña **Actions** y espera a que el flujo **Publish NOVAREX Global site** termine correctamente.
5. GitHub mostrará la dirección pública en la sección Pages o en el resultado del flujo de publicación.

## Estado y límites
- Este paquete está preparado para publicarse, pero no se considera publicado hasta que el alojamiento confirme una URL activa.
- El formulario abre un borrador de correo en el dispositivo; no transmite ni almacena datos en un servidor.
- No incluye backend, base de datos, procesamiento de pagos ni recepción de fondos.
- Antes de ofrecer servicios comercialmente, deben verificarse el nombre comercial, los datos de contacto, los registros necesarios y las autorizaciones aplicables.
- No se afirma una fecha de constitución o publicación anterior que no pueda verificarse.
